# 0.5.4 — NewRunScreen hotfix

Two regressions from the 0.5.3 new-run-view redesign that left operators unable to launch runs from the dashboard. Hotfix only — pure cherry-picks from the in-progress discovery work; no new features.

### Fixed

- DuplicateIds crash on Design features / Implement: the new workflow DataTable's auto-highlight-first-row fired in parallel with the dashboard's `default_workflow` plumbing, racing to mount `meeting-toggle-<id>` checkboxes before the previous removal flushed. Render is now idempotent on the currently-rendered workflow + uses `call_after_refresh` so the message-loop tick clears removals before re-mounting.
- Go / Cancel buttons getting squeezed off-screen on narrower terminals — the controls Horizontal was carrying Label + Input + Label + Input + Checkbox + Button + Button. Action buttons moved to their own row beneath; controls + buttons still read as one section but the buttons always render.
