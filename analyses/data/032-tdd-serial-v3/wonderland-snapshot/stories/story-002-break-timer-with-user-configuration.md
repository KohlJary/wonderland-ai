## Story 002: Break timer with user configuration

**Persona:** Keisha, 35, project manager, uses breaks to actually walk away from her desk. A five-minute break that keeps her tethered to the app defeats the purpose.

**Situation:**

Keisha's focus session ends. She knows she needs a break, but she knows herself: sometimes 5 minutes is enough, sometimes she needs 15. She doesn't want to reconfigure every single time.

**Need:**

As Keisha, I want to set my default break length once, and then have the app automatically move to a break timer when my focus session ends, so that I can step away without thinking about the app.

**Acceptance:**
- I can set a default break duration (5, 10, 15, or 30 minutes) in settings
- When a focus session ends, the break timer starts automatically at my configured length
- I can adjust the break length before it starts, without losing my default
- I can skip the break and go straight to the next focus session

**Tier:** core

**Confusion-flags:**
- Should the break timer also have a visual countdown, or is audio alone enough?
- What if Keisha wants different break lengths on different days? Is that v1 or fast-follow?
