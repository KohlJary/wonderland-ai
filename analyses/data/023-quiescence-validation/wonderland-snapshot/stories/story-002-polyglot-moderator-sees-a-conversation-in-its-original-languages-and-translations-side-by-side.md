## Story 002: Polyglot moderator sees a conversation in its original languages and translations side-by-side

**Persona:** Jin, 28, Tokyo. Fluent in Japanese, English, German. Moderates a global book club. She wants to follow all conversations regardless of language, but she also wants to catch translation errors or cultural nuance that machine translation misses.

**Situation:**

Jin is moderating a thread where Maya (English) and Klaus (German) are chatting. The conversation is drifting toward a cultural reference that matters to the book, and Jin needs to see both the original intent and what the translations are capturing.

**Need:**

As Jin, I want to see original-language messages alongside their translations, so that I can catch when translation is missing nuance and I can jump in with clarification if needed.

**Acceptance:**
- In the same thread, I see each message in its original language with the translation below or beside it (visual layout TBD by UI, but both are present).
- I can visibly distinguish which is original and which is translation.
- If I spot a translation problem, I can reply in a way that makes the correction clear to both parties.

**Tier:** enrichment

**Confusion-flags:**
- This is a different use case from the core (two-user conversation) but uses the same chat surface. I don't know if they should be the same feature or separate. The core feature is about breaking the language barrier; this feature is about seeing through translation. Different purposes.
- I don't know what 'thread' means here — is it a group chat, or just two-user with a third party observing? The acceptance criteria assume observation-mode, but I'm not sure that's a supported mode yet.
