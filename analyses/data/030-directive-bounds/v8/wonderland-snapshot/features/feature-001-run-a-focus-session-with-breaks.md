## Feature 001: Run a focus session with breaks

**Sources:** start-and-run-a-focus-session, take-a-break-and-return-to-work
**Personas:** knowledge worker trying to protect deep work time, student managing study sessions
**Stack span:** full-stack
**Tier:** v1

**Description:**

Start a timed focus session, automatically break when the timer ends, resume work after a break, and return to focus. The core pomodoro loop — what makes the app a focus timer at all.
