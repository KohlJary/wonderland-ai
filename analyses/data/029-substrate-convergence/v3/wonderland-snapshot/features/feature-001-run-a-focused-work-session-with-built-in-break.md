## Feature 001: Run a focused work session with built-in break

**Sources:** start-and-complete-a-focus-session, take-and-track-a-break
**Personas:** Knowledge Worker
**Stack span:** full-stack
**Tier:** v1

**Description:**

Start a 25-minute session, watch the timer count down, receive notification when the session ends, take a 5-minute break, start the next session. The app persists the session data and enforces the state machine (can't start a new session until the break ends).
