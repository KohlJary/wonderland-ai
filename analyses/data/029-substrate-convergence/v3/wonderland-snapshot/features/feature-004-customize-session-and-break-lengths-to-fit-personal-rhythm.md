## Feature 004: Customize session and break lengths to fit personal rhythm

**Sources:** adjust-session-and-break-lengths, trust-that-data-persists-across-app-restarts
**Personas:** Knowledge Worker
**Stack span:** full-stack
**Tier:** fast-follow

**Description:**

Change the default 25-minute session or 5-minute break to a custom duration, and have those lengths persist across app restarts. Supports the Pomodoro variant (50/10, 45/15, etc.) without forcing the default.
