## Story 003: User receives translated message and wants to see the original

**Persona:** Clara, 45, German-Italian bilingual, living in Berlin. She's in a conversation with someone in Japan and is fluent enough in English to spot when a translation might be off or miss a cultural nuance.

**Situation:**

Clara receives a message translated from Japanese to German. The translation feels slightly formal or she suspects there's a pun she's missing in the original.

**Need:**

As Clara, I want to tap or expand a translated message to see the original language version, so that I can verify meaning and catch context the translation might have smoothed over.

**Acceptance:**
- Clara receives a message in German that was translated from Japanese
- She can see a visual indicator that this is a translation (e.g., a small icon, label, or style difference)
- Tapping or clicking that indicator shows her the original Japanese message alongside the German
- She can toggle between views without leaving the conversation

**Tier:** core

**Confusion-flags:**
- Does every translated message show this affordance, or only some? If only some, which ones, and does that create confusion?
- When Clara sees the original, does she also see the app's confidence in the translation, or any alternate translation options? Or is that fast-follow?
- If she's curious about why a translation was chosen, there's no affordance to ask; that's probably okay for v1, but it's a gap.
