## Story 001: Monolingual user sends message across language boundary

**Persona:** Marcus, 67, retired German teacher, uses English for work emails but not daily. He joins to chat with his grandson in Tokyo who speaks English but prefers Japanese at home.

**Situation:**

Marcus opens the app, sees his grandson's name in the conversation list, and wants to send a casual message about the weather without reaching for a dictionary or translation tool.

**Need:**

As Marcus, I want to type in German and see my message appear in the conversation with an English translation visible to my grandson, so that I can communicate without the friction of switching languages.

**Acceptance:**
- Marcus types a German message in the input field
- He presses send; the message appears immediately in his view in German
- The same message appears in his grandson's view with an English translation below or alongside the original
- The conversation feels natural — translation is a visible aid, not a barrier

**Tier:** core

**Confusion-flags:**
- Unclear whether Marcus sees his own message in German or German+English. If both, does that feel redundant? Real users might find it either reassuring or cluttered.
- Timing: does the translation appear instantly, or is there a visible delay? If there's a delay, does Marcus's message feel 'sent' before translation arrives, or does it hang?
