## Story 004: User mistakenly sends message to wrong conversation

**Persona:** James, 34, English speaker, casual app user. He's chatting with colleagues in a work group and personal friends in another conversation.

**Situation:**

James types a casual joke into the wrong conversation thread and hits send before he notices. The message is now visible to his work contacts in a language he didn't intend.

**Need:**

As James, I want to [BLOCKED] delete or edit this message, so that I can correct the mistake.

**Acceptance:**
- This is explicitly out of scope for v1 per the directive (no message edit, no message delete)

**Tier:** fast-follow

**Confusion-flags:**
- This is a known gap and likely to be a pain point early. Users will assume they can undo. The team should be prepared for this to be the first post-launch feature request.
- Without edit/delete, the translated-message audit trail becomes more important for users to trust the system. They can't fix mistakes, so they need to verify what was actually sent.
