## Story 002: Break Timer Between Sessions

**Persona:** Priya, 34, therapist, uses Pomodoros for client notes. She needs breaks to actually rest — not drift into email. A configurable break timer holds her accountable to the structure.

**Situation:**

After a 25-minute focus session, Priya needs a 5-minute break to stretch, breathe, close her notes file. She wants the timer to enforce the break so she doesn't trick herself into 'just quickly checking email.'

**Need:**

As Priya, I want a break timer that starts automatically after my focus session ends, so that I'm forced to actually step away instead of seamlessly drifting into the next task.

**Acceptance:**
- Break timer starts automatically when focus session ends (no user action required)
- Break duration is configurable (default 5 minutes)
- User can skip the break if truly necessary, but must tap 'skip' explicitly (not accidental)
- Clear visual/audio signal when break ends

**Tier:** core

**Confusion-flags:**
- Unclear: after a break ends, does the next focus session start automatically, or does Priya have to manually start it? (affects flow friction)
- Unclear: does Priya see the break timer counting down, or is it silent/invisible as a way to actually rest her eyes?
