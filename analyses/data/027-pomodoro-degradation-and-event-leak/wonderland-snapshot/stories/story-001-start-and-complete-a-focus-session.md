## Story 001: Start and complete a focus session

**Persona:** Maya, 34, a freelance designer who works from home. She loses track of time in deep work and forgets to take breaks. She's heard pomodoro helps with both.

**Situation:**

Maya sits down to design work. She wants to commit to a focused 25 minutes without checking Slack or email. She needs a way to start this that is *faster* than opening a browser tab — it should be as frictionless as checking the time.

**Need:**

As Maya, I want to tap one button to start a 25-minute focus session, so that I can commit to deep work without the startup friction of opening a browser.

**Acceptance:**
- Tapping 'Start Session' begins a 25-minute countdown timer visible on screen
- The timer counts down in real-time; I can see exactly how much focus time remains
- I can see the timer without opening any menus or navigating anywhere — it is the default view
- When the 25 minutes ends, I receive a notification (visual, audio, or both) that pulls my attention

**Tier:** core

**Confusion-flags:**
- I'm not sure if the notification should *stop* the timer automatically or just alert me. Do I tap 'acknowledge' or does it auto-clear?
- I don't know if Maya wants the timer to keep running after the notification, or if 'focus time complete' means the session is truly done and she moves to break time.
