## Story 002: Polyglot moderator manages multi-language thread

**Persona:** Akira, 34, language teacher in Tokyo. He speaks Japanese, English, and German fluently. He is moderating the same book club but in a mixed-language group where some members speak only one language and some speak two.

**Situation:**

Akira wants to participate natively in multiple languages within the same conversation. He sometimes thinks of something in German, sometimes in English. He needs to see what's being said in all three languages to moderate fairly.

**Need:**

As Akira, I want to send messages in whichever language is natural in the moment and read the thread in all the languages being used, so that I can participate authentically and keep the conversation coherent across language groups.

**Acceptance:**
- Akira can type a message in Japanese, send it, and see it appear (untranslated to him, since it is his native language)
- Akira can see English and German translations of his Japanese message in the thread
- Akira can switch which language he is reading the thread in, or see multiple languages simultaneously
- When another member sends English, Akira sees both the English original and a Japanese translation

**Tier:** core

**Confusion-flags:**
- This is more complex than 'two monolinguals'. Does the MVP actually support this, or is MVP really 'two monolinguals in different language pairs'?
- If Akira is seeing multiple language pairs at once, how does the UI not become a wall of duplication?
- Does Akira need an explicit 'I speak this language' setting, or is it implicit from which language he types in first?
