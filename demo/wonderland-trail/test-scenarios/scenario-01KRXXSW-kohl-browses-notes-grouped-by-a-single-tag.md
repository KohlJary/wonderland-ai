## Scenario 118: Kohl browses notes grouped by a single tag

**GUID:** 01KRXXSWWJHYATNJ080FHBB1TM
**Severity:** degradation

**Setup:**

Kohl has created 5 notes, 3 of which are tagged 'kinetics'. She's viewing the note list and sees all 5 notes.

**Trigger:**

Kohl clicks on the 'kinetics' tag (assuming it's clickable / filterable in the list view) or selects it from a tag filter.

**Expected:**

The note list filters to show only the 3 notes tagged 'kinetics'. The filter is visually clear (e.g., 'Showing 3 notes tagged kinetics' or the tag is highlighted). Kohl can clear the filter to see all notes again.

**Concern:**

If tag filtering doesn't work, Kohl loses a key organizational tool. If the filter is invisible or unclear, Kohl won't realize why the list changed or how to restore it.

**Property:**

Tag-based filtering must be discoverable and reversible.
