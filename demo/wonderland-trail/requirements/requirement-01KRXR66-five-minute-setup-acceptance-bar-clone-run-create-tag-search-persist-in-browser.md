**Body:**

v1 is done when a developer can clone the repo from GitHub, follow the README's setup steps (install deps, run uvicorn and npm dev), open the app in their browser, create a note with a title and markdown body, tag it, search for it, see it in the results, reload the page, and see it still there with the tag intact. Total time: five minutes or less from clone to 'the notebook works.' This is the operator's acceptance bar for 'shipped.'

**Operator quote:**

> Developer can clone, run, and have a working notebook in their browser within five minutes. They can create a note, tag it 'research', close the tab, reload, and find the note still there with the tag intact.
