## Requirement 020: Explicitly out of scope for v1: multi-user accounts, cloud sync, real-time cross-tab sync, sharing, dark mode, keyboard shortcuts

**Body:**

The following are explicitly NOT v1 and will not be proposed in M2 or M3: multi-user accounts or per-user notebooks, cloud syncing to external services, real-time sync across browser tabs on the same device, sharing notebooks via URL or link, UI themes (dark mode, light mode), keyboard shortcuts beyond browser defaults, export/import (SQLite dumps are fine for backups, but 'export to JSON' and 'import from Markdown files' are post-launch).

**Operator quote:**

> Sharing notebooks, real-time sync between tabs, cloud syncing [are not v1].
