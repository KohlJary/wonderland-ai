## Requirement 017: Tag-based filtering: filter the note list to show only notes with a specific tag

**GUID:** 01KRXR66PGCDA33PSG8FDT2QJY

**Kind:** scope

**Body:**

v1 supports filtering the note list by tag. When the developer clicks a tag (or selects it from a list of all tags in use), the note list shows only notes that have that tag. Multi-tag filtering (show notes that have BOTH tag-A AND tag-B) is out of scope for v1.
