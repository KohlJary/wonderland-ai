## Requirement 013: Single-operator notebook with no authentication or setup

**GUID:** 01KRXR66PGCDA33PSG8FDT2QJT

**Kind:** scope
**Confidence:** operator_stated
**Source interview:** scope-interview
**Source question:** multiuser_vs_single

**Body:**

v1 is a single-device, single-operator use case. The developer clones the repo, runs the app (uvicorn + npm dev), and the notebook is immediately available in their browser with no login, no account setup, no configuration. The same developer using the same instance across sessions — that's the persona. Multi-user accounts, sharing, per-user notebooks: all fast-follow or post-launch.

**Operator quote:**

> Single-operator, no login — one person owns the notebook instance, opens it and uses it.
