## Scenario 114: Kohl opens a search result to edit it

**GUID:** 01KRXVK28H5RPDTG82TGG11W9Y
**Severity:** breakage

**Setup:**

Kohl has typed a search and is viewing results. She identifies a note she wants to update.

**Trigger:**

Kohl clicks on the note title or a 'View' button in the result row.

**Expected:**

The note opens in the editor pane (full screen or split). Title, body, and tags are populated from the result. Kohl can now edit the note. The search pane closes or minimizes.

**Concern:**

If clicking a result does nothing, Kohl can see the note exists but can't interact with it. The search result is inert. Feature doesn't complete the user need (find past notes → edit them).

**Property:**

result click navigation
