## Scenario 109: Kohl clears the search and returns to the main notes view

**GUID:** 01KRXVK28H5RPDTG82TGG11W9S
**Severity:** degradation

**Setup:**

Kohl has typed a search query and is viewing results. She decides to abandon the search and go back to the main notes list.

**Trigger:**

Kohl clicks a 'Clear Search' button or taps Escape in the search input.

**Expected:**

The search input clears, the results disappear, and the main notes list (or editor) is visible again. If she had a note open before searching, it's still visible (or can be re-opened from the list).

**Concern:**

If clearing search is hard or non-obvious, Kohl gets stuck in the search results and can't navigate back to her main workflow. UX dead-end.

**Property:**

search form reset
